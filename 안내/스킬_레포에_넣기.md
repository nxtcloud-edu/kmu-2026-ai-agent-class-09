# 스킬을 레포에 넣기

Kiro Crew는 내가 만든 스킬을 레포 밖의 `~/.kiro/crew/skills/<스킬 이름>/`에 저장한다. 스킬 폴더에는 절차(`SKILL.md`)와 직접 쓴 코드(`scripts/`)가 함께 있다. 그래서 스킬 폴더를 레포의 `구성/skills/`로 복사해야 기록이 남는다.

## 언제 하는가

- 스킬을 새로 만들었을 때
- 스킬을 고쳤을 때 (변경 기록을 쓰기 전에)
- 그 주의 `기록/주차/` 파일을 쓰기 전에

## 에이전트에게 맡기는 프롬프트

레포 폴더를 작업 폴더로 지정한 Kiro Crew 채팅에 아래 글을 그대로 붙여 넣는다.

```text
내가 만든 스킬을 이 레포에 사본으로 넣어 줘. 아래 순서를 지켜 줘.

1. ~/.kiro/crew/skills/ 안의 스킬 폴더 목록을 수정한 날짜가 최근인 순서로 보여 줘. 폴더마다 수정한 날짜와 SKILL.md의 description을 함께 보여 줘.
2. 내가 고른 스킬만 다룬다. 내가 고르기 전에는 아무것도 복사하지 마.
3. 고른 스킬 폴더를 통째로 이 레포의 구성/skills/<스킬 이름>/ 으로 복사해 줘. 레포에 같은 이름의 폴더가 이미 있으면, 바뀌는 내용을 먼저 보여 주고 내가 확인한 뒤에 덮어써 줘.
4. 복사한 파일에 토큰이나 비밀번호가 들어 있는지 검사해 줘. xoxb-, xapp-, sk-, AKIA, password, token, secret 이라는 문자열을 찾아 줘. 하나라도 나오면 커밋하지 말고 그 파일과 줄을 알려 줘.
5. git status로 바뀐 파일을 보여 줘. 그다음에 구성/skills/ 아래 파일만 git add 해 줘.
6. 커밋 메시지는 "구성: <스킬 이름> 스킬 사본 갱신"으로 해 줘. 푸시는 내가 확인한 뒤에 해 줘.
```

`crystallize`로 만든 스킬은 승인하기 전에는 후보로만 있다. 그래서 승인하기 전에는 1번 목록에 나오지 않는다.

## 확인할 것

- 레포의 `구성/skills/<스킬 이름>/SKILL.md`가 있다.
- 직접 쓴 코드가 있으면 `구성/skills/<스킬 이름>/scripts/`에 있다.
- GitHub 웹에서 푸시한 파일이 보인다.

## 직접 복사하는 명령

프롬프트 대신 직접 복사해도 된다. 레포 폴더에서 실행한다.

macOS:

```bash
cp -R ~/.kiro/crew/skills/<스킬 이름> 구성/skills/
```

Windows PowerShell:

```powershell
Copy-Item -Recurse "$env:USERPROFILE\.kiro\crew\skills\<스킬 이름>" 구성\skills\
```

## Kiro Crew가 아닌 도구를 쓰면

그 도구가 절차와 코드를 저장하는 위치를 프롬프트의 `~/.kiro/crew/skills/` 자리에 넣는다. 복사하는 곳은 똑같이 `구성/`이다.
