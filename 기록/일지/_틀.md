| 칸 | 일 1 | 일 2 |

| 실행되지 않았으면 그 까닭 | | |
| 받은 결과 | 한두 줄 요약 | |
| 내린 결정과 그 까닭 | | |
| 문제 | 틀리거나 불편했던 것 | |
| 손으로 한 일 | 무엇을, 무엇으로(예: Aside), 몇 분 | |
| 고친 것 | `변경.md`의 번호 | |
