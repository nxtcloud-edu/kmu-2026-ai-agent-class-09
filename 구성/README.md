# 구성

내 에이전트를 이루는 설정과 코드의 사본을 둔다. 이 폴더는 기록과 평가를 위한 사본이다. 도구에서 고치면 이 폴더도 같이 고친다.

다른 도구를 쓰면 같은 역할의 설정 파일이나 내보낸 파일을 둔다. 폴더와 파일 이름은 바꿔도 된다. 아래 표는 Kiro Crew를 쓸 때의 예다.

| 파일·폴더 | 가져오는 곳 |
|---|---|
| `에이전트.md` | 대시보드의 에이전트 설정을 옮겨 적는다. 에이전트가 여럿이면 에이전트마다 표를 하나씩 쓴다 |
| `skills/<스킬 이름>/` | `~/.kiro/crew/skills/<스킬 이름>/`을 통째로 복사한다 (방법은 README) |
| `스케줄.md` | 대시보드의 스케줄 화면을 옮겨 적는다 |
| `workflows/` | 저장한 워크플로우. 가져오는 방법은 9주차에 안내한다 |
| `가드레일.md` | 만든 차단 규칙을 옮겨 적는다 |
| `연결.md` | 일을 엮었으면 연결의 형식과 돈 기록을 쓴다(가점) |

커스텀 도구의 코드는 그 도구를 쓰는 스킬의 `scripts/`에 둔다.
